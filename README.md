# esp32c6

A collection of small Arduino sketches I’m writing in C++ for my ESP32-C6-DevKitC-1 v1.2 board. This is where I keep the things I build for fun while learning how the board works.

## Projects

- [Reaction Timer](./ReactionTimer/) - wait for the LED to turn green, then press BOOT to see your reaction time in milliseconds. Press too early and you’ll get a `BRUH`.
